# FINAL FANTASY RESONANCE — русский перевод

Неофициальный любительский перевод **FINAL FANTASY RESONANCE** (Steam) на русский язык.

**Перевод:** Maksami · **редактура и техническая часть:** Claude (ИИ-ассистент Anthropic)

**Сайт перевода:** https://185.105.109.35 — скачивание, список изменений, форма для сообщений об ошибках.

## Скачать

Готовый архив — в разделе [Releases](../../releases/latest): `FINAL_FANTASY_RESONANCE_RU_v1.5_Maksami.zip`.

## Что в переводе

- Весь текст игры: диалоги, меню, описания, задания, обучение, сообщения в бою — около 27 000 строк, из них переписано и отредактировано более 15 000.
- Живые диалоги, сверенные с английским и японским оригиналом; у каждого персонажа свой голос.
- Брань без цензуры у тех, кому она по характеру, — наёмников, бандитов, пиратов, злодеев.
- Просторечие у грубых персонажей, морской говор у пиратов, речь мастеров-инженеров, старинный слог у древних существ.
- Названия магии, предметов и монстров — по официальной русской версии FINAL FANTASY XV: Огонь-2, Ультразелье, Пух феникса, Багамут, ОЗ/ОМ.
- Переведена вся английская графика: надписи в бою («ХОРОШО!», «ПОТРЯСНО!!», «ПРОБИТИЕ», «ЗАЖИГАНИЕ!») и 49 скриншотов справки.
- Вёрстка проверена по размерам окон: текст не вылезает и не обрезается.

## Установка

1. Закройте игру.
2. Откройте папку игры: Steam → FINAL FANTASY RESONANCE → **Свойства** → **Установленные файлы** → **Обзор**.
3. Распакуйте архив так, чтобы папка `FFRS` из архива слилась с папкой `FFRS` игры (согласитесь на замену). Файлы окажутся в `FFRS\Content\Paks`.
4. Запустите игру: **Настройки → Игра → Язык текста → «Русский»**.

Язык озвучки — любой. Проверено на Steam-версии 1.0.1.0.

**Удаление:** удалите из `FFRS\Content\Paks` двенадцать файлов, имена которых начинаются с `FFRS-Windows_FULL_RU_`.

## Что в репозитории

| Папка | Содержимое |
|---|---|
| `edits/` | Слои правок перевода (JSON: ключ строки → русский текст), накладываются по порядку имён |
| `ancient/` | Стилизация речи древних персонажей (старый текст → новый) |
| `tools/` | Инструменты: чтение/сборка pak и IoStore (UE5), locres, проверки вместимости, единства терминов и качества, перерисовка картинок справки |
| `tools/tutspec/` | Разметка 49 скриншотов справки (что и где заменить) |
| `docs/` | Правила стиля и глоссарий |

Файлы самой игры (тексты, картинки, шрифты) и сторонние библиотеки в репозиторий **не входят**: все права на игру принадлежат SQUARE ENIX. Для сборки из исходников нужны собственная копия игры, базовые pak-файлы перевода в папке `base/`, `oo2core_7_win64.dll` (Oodle) и `texconv.exe` ([Microsoft DirectXTex](https://github.com/microsoft/DirectXTex/releases)) в `tools/`.

Порядок сборки текста:

```
python -I tools/ancient.py
python -I tools/unwrap.py
python -I tools/nbsp.py
python -I tools/normalize.py
python -I tools/disputes.py
python -I tools/qa.py
python -I tools/build.py base/FFRS-Windows_FULL_RU_Stage04_Remaining_17000_P.pak ru/ru.json build/final.pak
```

Графика: `python -I tools/gfx_build.py`.
